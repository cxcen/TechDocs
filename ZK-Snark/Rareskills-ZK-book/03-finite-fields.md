# 零知识证明中的有限域与模运算

*本文是系列文章的第三篇，将在零知识证明电路的语境中介绍有限域。前两章分别是 [P vs NP 及其在零知识证明中的应用](https://www.rareskills.io/post/p-vs-np)和[算术电路](https://www.rareskills.io/post/arithmetic-circuit)。*

上一章讨论算术电路时，我们指出了一个限制：无法编码 $2/3$，因为二进制不能精确表示它。我们还指出，当时没有明确处理上溢的方法。

这两个问题都可以通过一种称为*有限域*的算术变体自然解决；有限域在密码学中应用广泛。

## 有限域

给定一个素数 `p`，取整数集合 $\set{0, 1, 2, …, p-1}$，并把加法和乘法定义为模 $p$ 运算，就能构造一个包含 `p` 个元素的有限域。我们先只讨论元素个数为素数的域。

例如，如果素数 $p$ 为 $7$，有限域中的元素就是 $\set{0, 1, 2, 3, 4, 5, 6}$。任何超出该范围（$≥ p$ 或 $< 0$）的数，都会通过取模映射到范围内某个“等价”的数。“等价”在这里的严格术语是*同余*。

取模计算一个数除以该素数后的余数。例如，模数为 7 时，12 与 5 *同余*，即 $12 \pmod 7 = 5$；14 与 0 同余。类似地，把 3 和 5 相加，结果 8 与 1 同余（8 mod 7 = 1）。下面的动画对此进行了演示：

![数轴动画](https://static.wixstatic.com/media/706568_27817a32acf7429ca035667488ebce27~mv2.gif)

在 Python 中，上述计算可以写成：

```python
p = 7
result = (3 + 5) % p
print(result) # prints 1
```

本章进行计算时，总会把结果表示为 $0…(p-1)$ 范围内的数，也就是有限域 `p` 的元素集合。例如，2 * 5 = 10，在模 7 意义下将其“化简”为 3。

请注意，3 + 5“上溢”了上限 6。**在有限域中，上溢不是错误；我们把上溢行为定义为计算本身的一部分。** 在模 7 的有限域中，5 + 3 按定义就是 1。

下溢的处理方式类似。例如，$3 - 5 = - 2$，但在模 7 意义下结果是 $5$，因为 $7 - 2 = 5$。

## 模运算的工作原理

在一般编程语言中，有限域加法可以写成 `(6 + 1) % 7 == 0`；数学记号通常写作：

$$
0 = 6 + 1 \pmod 7
$$

更一般地：

$$
c = a + b \pmod p
$$

其中 $a$ 和 $b$ 是有限域中的数，$c$ 是余数，它把所有 $≥ p$ 和 $< 0 $ 的数映射回集合 $\set{0, 1, …, p - 1}$。

记号 $\pmod p$ 表示*所有*算术都对 $p$ 取模。例如：

$$
a + b = c + d \pmod p
$$

等价于 Python 或 C 中的 `(a + b) % p == (c + d) % p`。

乘法的工作方式类似：先把数字相乘，再取模：

$$
3 = 4 × 6 \pmod 7 = 24 \pmod 7 = 3
$$

有限域中的数称为“元素”。

## $p$ 与域的阶

我们把用于取模的数称为 $p$。在本文所有示例中，它都是素数。在更广泛的数学语境中，$p$ 不一定是素数，但我们只关心 $p$ 为素数的情况。

由于这一限制，域的*阶*始终等于 $p$。域的*阶*是域中的元素个数。用于取模的数更一般地称为域的*特征*。

例如，当 $p = 5$ 时，元素为 $\set{0, 1, 2, 3, 4}$。一共有 5 个元素，因此该域的阶为 5。

## 加上 $p$ 不改变元素

任何元素加上 $p$ 后仍是原来的元素。例如，$(3 + 7) \pmod 7 = 3$。请看下面动画中的示例：

## 加法逆元

考虑 $5 + (-5) = 0$。

在数学中，$a$ 的加法逆元是满足 $a + b = 0$ 的数 $b$。通常在一个数前加负号来表示其加法逆元。按照定义，$-a$ 就是与 $a$ 相加得到 0 的数。

### 加法逆元的一般规则

- 零的加法逆元是它自身。
- 每个数恰好有一个加法逆元。

这些规则同样适用于有限域。虽然有限域中没有像 $-5$ 这样带负号的元素，但在取模运算下，某些元素相对于彼此可以像负数一样“表现”。

在普通算术中，$-5$ 是与 $5$ 相加得到 $0$ 的数。如果有限域的 $p = 7$，那么可以把 $2$ 视为 $-5$，因为 $(5 + 2) \pmod 7 = 0$。类似地，也可以把 $5$ 视为 $-2$，因为它们互为加法逆元。更严格地说，$-2$ 与 $5$ 同余，即 $-2 \equiv 5 \pmod 7$。

要计算某个元素的加法逆元，只需计算 $p - a$，其中 $a$ 是目标元素。例如，要找 14 模 23 的加法逆元，计算 $23 - 14 = 9$。可以看到，$14 + 9 \pmod {23} = 0$。$p$ 与零同余，因此这等价于用 $0 - 5$ 计算 $-5$。

与实数一样：

- 有限域中的每个元素恰好有一个加法逆元；
- 零的加法逆元是它自身。

有限域中加法逆元的一般模式是：域前半部分的元素与后半部分的元素互为加法逆元。零是例外，因为它的加法逆元是自身。下图中由绿线连接的数字，在 $p = 7$ 的域中互为加法逆元：

## 乘法逆元

考虑 $5 × (1/5) = 1$。

$a$ 的乘法逆元是满足 $ab = 1$ 的数 $b$。除零以外，每个元素都有乘法逆元。对“普通数”而言，乘法逆元是 $1 / \text{num}$。例如，$5$ 的乘法逆元是 $1/5$，$19$ 的乘法逆元是 $1/19$。

虽然有限域中没有分数，但仍然可以找到一些数对，使它们相加或相乘时像分数一样“表现”。

例如，在有限域 $p = 7$ 中，$4$ 的乘法逆元是 $2$，因为 $4 * 2 = 8$，且 $8 \pmod 7 = 1$。所以，$2$ 在该有限域中像 $1/4$ 一样“表现”；更严格地说，$1/4$ 与 $2 \pmod 7$ 同余。

### 有限域算术中乘法逆元的一般规则

- 0 没有乘法逆元；
- 1 的乘法逆元是它自身；
- 每个数（0 除外）恰好有一个乘法逆元，该逆元可能就是它自身；
- 值为 $(p - 1)$ 的元素，其乘法逆元是它自身。例如，在 $p = 103$ 的有限域中，$1$ 和 $102$ 的乘法逆元都是自身；在 $p = 23$ 的有限域中，$1$ 和 $22$ 的乘法逆元也是自身（下一节会解释原因）。再如，在模 5 的有限域中，1 和 4 的乘法逆元分别是自身。$4 \times 4 = 16$，且 $16 \pmod 5 = 1$。

### 为什么值为 $p - 1$ 的元素是自身的乘法逆元

$-1$ 与自身相乘得到 $1$，因此在实数中，$-1$ 的乘法逆元就是它自身。值为 $(p - 1)$ 的元素与 $-1$ 同余，所以可以预期 $(p - 1)$ 的乘法逆元是它自身，而事实确实如此。

还可以从另一个角度理解为何 $p - 1$ 是自身的乘法逆元：$(p - 1)(p - 1) = p² - 2p + 1$。由于 $p$ 与 $0$ 同余，$p² - 2p + 1$ 可化简为 $0^2 - 2*0 + 1 = 1$。

#### 有限域上算术电路的解

如果在普通数上考虑下面的算术电路，会预期 `x = -1` 是唯一的满足赋值。

```python
x * x === 1
x + 1 === 0
```

在有限域中，满足赋值是与 $-1$ 同余的元素，也就是 $p - 1$。

### 使用费马小定理计算乘法逆元

[费马小定理](https://en.wikipedia.org/wiki/Fermat%27s_little_theorem)指出：

$$
a^{p}=a\pmod p, a\neq0
$$

换句话说，把一个非零元素提升到 $p$ 次幂，会得到该元素本身。例如：

- $3⁵ \pmod 5 = 3$
- $4⁷ \pmod 7 = 4$
- $14⁵³ \pmod {53} = 14$

现在，考虑将 $aᵖ = a \pmod p$ 两侧同时除以 $a$（请记住 $a ≠ 0$）：

$$
a^p=a
$$
$$
\frac{a^p}{a}=\frac{a}{a}
$$
$$
a^{p-1}=1
$$


可以把结果写成：

$$
a(a^{p-2}) = 1
$$

**这意味着 $aᵖ⁻² \pmod p$ 是 $a$ 的乘法逆元**，因为 $a$ 与 $aᵖ⁻²$ 相乘等于 1。

例如：

- 在有限域 $p = 7$ 中，$3$ 的乘法逆元是 $5$。$3⁷⁻² = 5 \pmod 7$
- 在有限域 $p = 11$ 中，8 的乘法逆元是 $7$。$8¹¹⁻² = 7 \pmod {11}$

这种方法的优点是，可以使用以太坊中的 `expmod` [预编译合约](https://www.rareskills.io/post/solidity-precompiles)，在智能合约里计算模逆元。

实践中，这并不是计算乘法逆元的理想方式，因为把一个数提升到很大的幂会耗费大量计算。计算乘法逆元的库会在内部使用更高效的算法。不过，如果没有这样的库，又需要一个快捷简单的方案，并且计算大指数的代价并不过高，就可以使用费马小定理。

## 使用 Python 计算乘法逆元

在 Python 3.8 或更高版本中，可以使用 `pow(a, -1, p)` 计算 `a` 在有限域 `p` 中的乘法逆元。`pow` 的第一个参数是底数，第二个是指数，第三个是模数。

例如：

```python
p = 17
print(pow(5, -1, p))
# 7
assert (5 * 7) % p == 1
```

## 乘法逆元的加法与普通分数加法一致

在有限域 `p = 7` 中，2 和 4 互为乘法逆元，因为 $(2 \times 4) \pmod 7 = 1$。这意味着在有限域 $p = 7$ 中，$4$ 与 $1/2$ 同余，$2$ 与 $1/4$ 同余。

之所以说有限域 $p = 7$ 中 $4$ 与 $1/2$ 同余，是因为 $2 \times \mathsf{mul\_inv}(2) = 1$。在该有限域中，$2$ 的乘法逆元是 $4$，所以可以把 $4$ 当作 $1/2$。

对实数而言，$1/2 + 1/2$ 的结果应为 $1$。有限域中也是如此。因为 $4$ 像 $1/2$ 一样“表现”，所以预期 $4 + 4 \pmod 7 = 1$，事实确实如此。

可以把 $5/6$ 看作运算 $5 * (1/6)$，也就是 $5 \times \mathsf{mul\_inv}(6)$，从而在有限域中编码它。

考虑 $1/2 + 1/3 = 5/6$。如果有限域的 $p = 7$，那么 $1/2$ 是 $2$ 的乘法逆元，$1/3$ 是 3 的乘法逆元，$5/6$ 则是 $5$ 乘以 6 的乘法逆元：

```python
p = 7
one_half = pow(2, -1, p)
one_third = pow(3, -1, p)
five_over_six = (pow(6, -1, p) * 5) % p

assert (one_half + one_third) % p == five_over_six
# True
```

在有限域中计算“分数”的一般方法是：分子乘以分母的乘法逆元，再对 `p` 取模：

```python
def compute_field_element_from_fraction(num, den, p):
	inv_den = pow(den, -1, p)
	return (num * inv_den) % p
```

当分母是 `p` 的倍数时，无法这样计算。例如，有限域 $p = 7$ 无法表示 $1/7$，因为 `pow(7, -1, 7)` 无解。取模会计算除法后的余数，而 $7/7$ 的余数为零；更一般地，当 $d$ 是 $7$ 的倍数时，$7/d$ 为零。乘法逆元意味着一个数与其逆元相乘得到 $1$，但如果其中一个数为零，就不存在任何数与零相乘能得到 1。

**练习：** 在 Python 中运行 `pow(7, -1, 7)`。应该会抛出异常 `ValueError: base is not invertible for the given modulus`。$7$ 模 $7$ 等于零，不存在任何数与零相乘能得到 $1$。

### 有限域“除法”不会损失精度

在大多数编程语言中计算 `1 / 3` 会损失精度，因为二进制无法表示 $0.\overline{3}$。

但有限域中的 `1 / 3` 就是 3 的乘法逆元。

这意味着下面的算术电路：

```rust
x + y + z === 1;
x === y;
y === z;
```

在有限域中存在精确解。如果把定点数或浮点数作为算术电路的数据类型，就无法可靠做到这一点（例如，0.33333 + 0.33333 + 0.33333 的结果是 0.99999，而不是 1）。

下面的 Python 实现演示了该电路：

```python
p = 11

# x, y, z have value 1/3
x = pow(3, -1, 11)
y = pow(3, -1, 11)
z = pow(3, -1, 11)

assert x == y;
assert y == z;
assert (x + y + z) % p == 1
```

## 有限域元素没有传统意义上的“奇数”或“偶数”

如果一个数除以二没有余数，我们就说它是“偶数”。

**在有限域中，任何元素除以 2 都没有余数。**

也就是说，“除以二”实际上是乘以 2 的乘法逆元，其结果总是另一个域元素，不存在“余数”。

不过，如果拥有域元素的二进制表示，就可以判断把该元素转换为整数后是奇数还是偶数。如果最低有效位为 1，那么该数是奇数——这里是把它解释为整数，而不是有限域元素。

## Python 有限域库

在 Python 中反复编写 `pow` 和 `% p` 有些繁琐，读者可以改用 [galois 库](https://pypi.org/project/galois/)（有限域有时也称为 Galois field，即“伽罗瓦域”）。可以使用 `python3 -m pip install galois` 安装。

下面把上一节的分数加法代码 $(1/2 + 1/3 = 5/6)$ 改写为使用 `galois` 库。该库重载了数学运算符，使其在有限域中工作：

```python
import galois
GF7 = galois.GF(7) # GF7 is a class that wraps 7

one_half = GF7(1) / GF7(2)
one_third = GF7(1) / GF7(3)
five_over_six = GF7(5) / GF7(6)

assert one_half + one_third == five_over_six
```

运算 `1 / GF(a)` 会计算 `a` 的乘法逆元。

`galois` 库可以通过在前面添加负号来计算加法逆元：

```python
negative_two = -GF7(2)
assert negative_two + GF7(2) == 0
```

## 分数乘法也保持一致

本例使用有限域 `p = 11`。

对普通数而言，$1/3 * 1/2 = 1/6$。

下面在有限域中执行相同运算：

```python

import galois
GF = galois.GF(11)

one_third = GF(1) / GF(3)
one_half = GF(1) / GF(2)
one_sixth = GF(1) / GF(6)

assert one_third * one_half == one_sixth
```

**练习：** 使用 galois 库检查有限域 $p = 17$ 中 $3/4 * 1/2 = 3/8$。

## 对所有非零 a、b，都有 a × b ≠ 0

在有限域中，两个元素相乘得到零，当且仅当其中至少一个元素本身为零。普通数也具有这一性质。

为了理解这一点，考虑有限域 $p = 7$。要让两个数相乘后结果为 $0$，其中一项 $a$ 必须是 7 的倍数，使 $a \pmod 7$ 为零。但 $\set{0, 1, 2, 3, 5, 6}$ 中没有任何数是 7 的倍数，因此这种情况不可能发生。

设计算术电路时，我们会频繁使用这一事实。例如，如果知道：

```python
x₁ * x₂ * ... * xₙ ≠ 0
```

那么即使不知道具体值，也可以确定所有变量 `x₁, x₂, xₙ` 都非零。

下面说明如何在实际算术电路中运用这个技巧。假设有信号 `x₁, x₂, x₃`，希望约束其中至少一个信号的值为 8，但不指定是哪一个。首先计算当前域中 8 的加法逆元 `a_inv(8)`，然后写出：

`(x₁ + a_inv(8))(x₂ + a_inv(8))(x₃ + a_inv(8)) === 0`

也可以写成：

`(x₁ - 8)(x₂ - 8)(x₃ - 8) === 0`

其中约定 `-8` 表示有限域中 8 的加法逆元。

只要有一个信号的值为 8，对应项就会变成零，整个表达式的乘积也会为零。这个技巧依赖以下两个事实：

- 如果所有项都非零，表达式不可能得到零；
- 8 的加法逆元是唯一的，而 8 也是 8 的加法逆元之唯一加法逆元。换句话说，除了 8，不存在其他值能使 8 + inv(8) 为零。

因此，算术电路 `(x₁ + a_inv(8))(x₂ + a_inv(8))(x₃ + a_inv(8)) === 0` 表示 `x₁, x₂, xₙ` 中至少有一个值为 8。

## 有限域运算满足结合律、交换律和分配律

与普通算术一样，模运算也满足结合律、交换律和分配律，即：

**结合律**

$(a + b) + c = a + (b + c) \pmod p$

**加法交换律**

$(a + b) = (b + a) \pmod p$

**乘法交换律**

$ab = ba \pmod p$

**分配律**

$a(b + c) = ab + ac \pmod p$

## 模平方根

在“普通数学”中，完全平方数具有整数平方根。例如，25 的平方根为 5，49 的平方根为 7，依此类推。

### 有限域元素无需是完全平方数，也可能存在平方根

考虑 $5 × 5 \pmod {11} = 3$。这意味着模 11 意义下，3 的平方根是 5。由于有限域会环绕，有限域元素无需是完全平方数，也可能存在平方根。

与普通平方根一样，有限域中的模平方根也有两个解，分别对应正值和负值。元素 0 是例外，它只有平方根 0。

在模 11 的有限域中，以下元素具有平方根：

| 元素 | 第一个平方根 | 第二个平方根 |
| --- | --- | --- |
| 0 | 0 | 不适用 |
| 1 | 1 | 10 |
| 3 | 5 | 6 |
| 4 | 2 | 9 |
| 5 | 4 | 7 |
| 9 | 3 | 8 |

**练习：** 验证表中给出的平方根在模 11 的有限域中确实正确。

请注意，与实数一样，第二个平方根总是第一个平方根的加法逆元。

例如：

- 在普通数学中，$9$ 的平方根是 $3$ 和 $-3$，二者互为加法逆元。
- 在有限域 $p = 11$ 中，9 的平方根是 3 和 8。8 是 3 的加法逆元，因为 $8 + 3 \pmod {11}$ 为 $0$，就像 $-3$ 是 $3$ 的加法逆元一样。

元素 2、6、7、8 和 10 在有限域 $p = 11$ 中没有模平方根。可以把从 0 到 10 的每个元素分别平方，观察到结果中从未出现 2、6、7、8 和 10。

```python
numbers_with_roots = set()
p = 11
for i in range(0, p):
    numbers_with_roots.add(i * i % p)

print("numbers_with_roots:", numbers_with_roots)
# numbers_with_roots: {0, 1, 3, 4, 5, 9}
```

注意，3 不是完全平方数，但在这个有限域中有平方根。

### 计算模平方根

可以使用 Python 的 [libnum 库](https://github.com/hellman/libnum)计算模平方根。下面计算 5 模 11 的平方根。对本文用途，函数 `has_sqrtmod_prime_power` 和 `sqrtmod_prime_power` 的第三个参数可以设为 1。

```python
# install libnum with `python -m pip install libnum`

from libnum import has_sqrtmod_prime_power, sqrtmod_prime_power
has_sqrtmod_prime_power(5, 11, 1) # True
list(sqrtmod_prime_power(5, 11, 1)) # [4, 7]
# square roots generally have two solutions. 4 and 7 are the square roots of 5 (mod 11)
```

当 `p` 可写成 `4k + 3`，其中 `k` 为整数时，可以按以下方式计算模平方根：

```python
def mod_sqrt(x, p):
	assert (p - 3) % 4 == 0, "prime not 4k + 3"
	exponent = (p + 1) // 4
	return pow(x, exponent, p) # x ^ e % p
```

上述函数返回 x 模 p 的两个平方根之一。另一个平方根可以通过计算返回值的加法逆元得到。如果素数不是 `4k + 3` 的形式，就必须使用 [Tonelli–Shanks 算法](https://en.wikipedia.org/wiki/Tonelli–Shanks_algorithm)计算模平方根（上面的 libnum 库实现了该算法）。

**这意味着算术电路 `x * x === y` 可能有两个解。** 例如，在有限域 `p = 11` 中，可能会认为算术电路 `x * x === 4` 只允许取值 2，因为 -2 不是有限域元素。然而，这一假设大错特错！赋值 `x = 9` 与 -2 同余，同样满足该电路。

**练习：** 使用上面的代码片段，计算有限域 `p = 19` 中 5 的模平方根。代码只会给出其中一个答案，如何计算另一个？

## 有限域中的线性方程组

上一章指出，算术电路本质上是一组等式。有限域中的线性方程组与普通数上的线性方程组有许多共同性质，但也存在一些起初可能出人意料的差异。算术电路是在有限域上计算的，因此必须理解这些意外偏差可能出现在哪里。

[线性方程组](https://math.libretexts.org/Bookshelves/Algebra/Algebra_and_Trigonometry_1e_(OpenStax)/11%3A_Systems_of_Equations_and_Inequalities/11.01%3A_Systems_of_Linear_Equations_-_Two_Variables)是一组包含若干未知量（变量）的直线方程，需要一起求解。要找出线性方程组的唯一解，必须为每个变量找到一个数值，使方程组中的所有等式同时成立。

实数上的线性方程组有以下三种情况：

1) **无解：** 在二维空间中，两个等式表示平行线；在三维或更高维空间中，它们永不相交。

![平行线](https://static.wixstatic.com/media/706568_3c9b8369fd064afe93c2a7ac7816bbf7~mv2.gif)

2) **一个解：** 直线相交于一点。

![相交直线](https://static.wixstatic.com/media/706568_140802e7d9534b448073e17ea95ff821~mv2.gif)

3) **无穷多个解：** 如果两个等式表示同一条直线，就有无穷多个交点，线性方程组也有无穷多个解。

![两条重合直线](https://static.wixstatic.com/media/706568_a16e84f93c44406486a5a1ee540f281c~mv2.gif)

有限域上的方程组同样可能有：

1. 零个解，或者

2. 一个解，或者

3. $p$ 个解，也就是与域的阶相同数量的解。

**但是，实数上的线性方程组有零个、一个或无穷多个解，*并不意味着*同一个线性方程组在有限域上也相应地有零个、一个或 `p` 个解。**

之所以强调这一点，是因为我们会用算术电路及其信号赋值来编码 NP 类问题的解。但由于算术电路使用有限域编码，最终的编码方式可能无法捕捉我们原本试图建模的等式行为。

下面三个示例展示了在有限域上计算时，方程组的行为会如何改变。

### 示例 1：在普通数上有一个解的方程组，在有限域中可能有 `p` 个解

例如，绘制：

$$
x+2y=1
$$
$$
6x+y=6
$$

![两条只有一个交点的直线](https://static.wixstatic.com/media/706568_26aa180e616f434ab16a76673e03b530~mv2.png/v1/fill/w_1214,h_712,al_c,q_90,usm_0.66_1.00_0.01,enc_auto/706568_26aa180e616f434ab16a76673e03b530~mv2.png)

在实数上，它只有一个解 $(1, 0)$；但在有限域 $p = 11$ 上，它有 11 个解：$\set{(0, 6), (1, 0), (2, 5), (3, 10), (4, 4), (5, 9), (6, 3), (7, 8), (8, 2), (9, 7), (10, 1)}$。

**不要认为一个在实数上只有一个解的方程组（算术电路），在有限域中也只有一个解！**

下面绘制有限域上的方程组解，以说明两个等式“处处相交”，即满足两个等式的点集完全相同：

![相同方程的模运算图](https://static.wixstatic.com/media/706568_079fc534789a431cbe3e52bf0081012c~mv2.png/v1/fill/w_1234,h_758,al_c,q_90,usm_0.66_1.00_0.01,enc_auto/706568_079fc534789a431cbe3e52bf0081012c~mv2.png)

这看起来可能极其违反直觉，下面看看它为何会发生。求解原方程：

$$
x+2y=1
$$
$$
6x+y=6
$$

得到关于 $y$ 的表达式：

$$
y = 1/2 - 1/2*x
$$
$$
y=6-6x
$$

$1/2$ 是 $2$ 的乘法逆元。在有限域 $p = 11$ 中，$6$ 是 $2$ 的乘法逆元，即 $2 * 6 \pmod {11} = 1$。因此，$x + 2y = 1$ 和 $6x + y = 6$ 在有限域 $p = 11$ 中实际上是同一个等式。也就是说，等式 $y = 1/2 - 1/2x$ 编码到有限域后成为 $y = \mathsf{mul\_inv}(2) - \mathsf{mul\_inv}(2)x$，即 $y = 6 - 6x$，与方程组中的另一个等式相同。

### 示例 2：在普通数上有一个解的方程组，在有限域中可能无解

另一个违反直觉的情况是：一个在实数上有唯一解的方程组，在有限域中可能无解：

$$
x + 2y=1
$$
$$
7x+3y=2
$$

![实数上另一组只有一个交点的方程](https://static.wixstatic.com/media/706568_c194df52697f4010943ff4e927f206b6~mv2.png/v1/fill/w_1480,h_604,al_c,q_90,usm_0.66_1.00_0.01,enc_auto/706568_c194df52697f4010943ff4e927f206b6~mv2.png)

显然，这个方程组有一个交点，但在有限域中却无解。

下面给出两个等式在有限域中的图：

![有限域中没有交点的图](https://static.wixstatic.com/media/706568_a737888a0bbc4f4e88d4209b47d0911f~mv2.png/v1/fill/w_1164,h_714,al_c,q_90,usm_0.66_1.00_0.01,enc_auto/706568_a737888a0bbc4f4e88d4209b47d0911f~mv2.png)

**练习：** 编写代码，暴力枚举 `(x, y)` 的所有组合，其中 `x = 0..10, y = 0..10`，验证上述方程组在有限域 `p = 11` 中无解。

为什么这个方程组在有限域 $p = 11$ 中无解？

在实数上求解：

$$
x + 2y=1
$$
$$
7x+3y=2
$$

得到：

$$
x = \frac{1}{11},\space y=\frac{5}{11}
$$

上述分数在有限域 `p = 11` 中没有同余元素。

回顾一下，除以一个数等价于乘以该数的乘法逆元。还要记住，域的阶（这里为 11）没有乘法逆元，因为域的阶与 0 同余。

`a` 的乘法逆元是值 `b`，它满足 `a * b = 1`。但是，如果 `a = 0`（或与它同余的任何值），`b` 就无解。因此，实数解的表达式无法转换成当前有限域的元素。

所以上述解 (x, y) 不属于该有限域。因此，在有限域 `p = 11` 中，`x + 2y = 1` 和 `7x + 3y = 2` 是平行线。

还可以从另一个角度理解。求出关于 y 的表达式：

$$
y = 1/2 - x/2
$$
$$
y=2/3-7x/3
$$

上一节已经看到，`6` 是 `2` 的乘法逆元，因此第一个等式的“斜率” `-1/2` 就是 `-6`，在有限域中等价于 `5`。第二个等式的斜率通过 `-7` 乘以 `3` 的乘法逆元得到：`(-7 * pow(3, -1, 11)) % 11 = 5`。这说明它们在有限域中的斜率相同。

斜率是 `x` 在 `y = c + bx` 形式中的系数。对上面的两个等式，第一个斜率是 `-1/2`，第二个斜率是 `-7/3`。把这两个分数都转换为有限域 `p = 11` 中的元素，会得到相同的值 `5`：

```python
import galois
GF11 = galois.GF(11)

negative_1 = -GF11(1)
negative_7 = -GF11(7)

slope1 = GF11(negative_1) / GF11(2)
slope2 = GF11(negative_7) / GF11(3)

assert slope1 == slope2 # 5 == 5
```

这一事实对下面的算术电路意味着：

```python
x + 2 * y === 1
7 * x + 3 * y === 2
```

该算术电路在有限域 `p = 11` 中没有满足赋值。

然而，在有限域 `p = 11` 中，它有 11 个解：$\set{(0, 7), (1, 1), (2, 6), (3, 0), (4, 5), (5, 10), (6, 4), (7, 9), (8, 3), (9, 8), (10, 2)}$。这些解绘制如下：

**练习：** 把两个等式转换为有限域表示，验证它们相同。

假设把这个方程组编码为算术电路：

## 有限域中的多项式

在算术电路一章中，我们使用多项式 `x(x - 1) === 0` 强制 `x` 只能取 0 或 1。也可以把它写成多项式等式：完全展开表达式，直到它表示为 x 的不同次幂分别乘以系数。本例得到 `x² - x === 0`。

对于该例，假定多项式 `x² - x === 0` 在有限域中（以及实数中）只有解 0 和 1 是正确的。但一般情况下，不应假定一个多项式在实数上和有限域中具有相同的根，稍后会给出一些反例。

尽管如此，有限域上的多项式仍与实数上的多项式共享许多性质：

- 次数为 $d$ 的多项式至多有 $d$ 个根。多项式 $p(x)$ 的根是满足 $p(r) = 0$ 的值 $r$。
- 如果把两个多项式 $p_1$ 和 $p_2$ 相加，$p_1 + p_2$ 的次数至多为 $\max(\deg(p_1), \deg(p_2))$。$p_1 + p_2$ 的次数也可能小于 $\max(\deg(p_1), \deg(p_2))$。例如，$p_1=x³ + 5x + 7$，而 $p_2 = -x³$。
- 有限域中的多项式加法满足结合律、交换律和分配律。
- 如果把两个多项式 $p_1$ 和 $p_2$ 相乘，乘积的根是 $p_1$ 与 $p_2$ 根的并集。

以 $y = x² \pmod {17}$ 为例绘图：

![x^2 mod 17 的图](https://static.wixstatic.com/media/706568_3917656775e4477598b9afad9dea92d7~mv2.png/v1/fill/w_1428,h_856,al_c,q_90,usm_0.66_1.00_0.01,enc_auto/706568_3917656775e4477598b9afad9dea92d7~mv2.png)

$x$ 的定义域是有限域中的元素，输出（值域）也必须是有限域的元素。请注意，所有 $x$ 和 $y$ 值都位于区间 $[0,16]$ 中。有限域上的多项式只能取小于 $p$ 的 $x$ 和 $y$ 值。

在有限域 $p = 17$ 中，与 $y = -x²$ 等价的是 $y = 16x² \pmod {17}$，因为 16 是该有限域中 1 的加法逆元。多项式 $y = 16x² \pmod {17}$ 的图如下：

![y = 16x^2 mod 17 的图](https://static.wixstatic.com/media/706568_983e1638b445495ebf2d99ab0d4f7027~mv2.png/v1/fill/w_1440,h_864,al_c,q_90,enc_auto/706568_983e1638b445495ebf2d99ab0d4f7027~mv2.png)

### 在实数中没有根的多项式，在有限域中可能有根

与前面的线性方程组示例一样，不应假定一个多项式在实数中和有限域中具有相同的根。

下面绘制有限域 $p = 17$ 中的 $y = x² + 1$。在实数中，$y = x² + 1$ 没有实根；但在有限域中，它有两个根 $4$ 和 $13$，下图用红点标出：

![y = x^2 + 1 mod 17 的图](https://static.wixstatic.com/media/706568_c1a9510ce859456d8a20fb705c35c604~mv2.png/v1/fill/w_1436,h_871,al_c,q_90,enc_auto/706568_c1a9510ce859456d8a20fb705c35c604~mv2.png)

下面解释为什么 $y = x² + 1$ 在实数中没有根，却在有限域 $p = 17$ 中有根。在有限域 $p = 17$ 中，17 与零同余。因此，如果为 $x$ 代入一个值，使 $x² + 1$ 变成 $17$，多项式输出的就是零，而不是 $17$。求解 $x² + 1 = 17$，得到 $x² = 17 - 1 = 16$。在有限域 $p = 17$ 中，$x² = 16$ 的解为 $4$ 和 $13$。因此，$y = x² + 1$ 在有限域 $p = 17$ 中的根是 $4$ 和 $13$。

### 在实数中有根的多项式，在有限域中可能没有根

考虑多项式 $y = x² − 5$。可以看到，它的根为 $\sqrt{5}$ 和 $-\sqrt{5}$。然而，在模 17 的有限域上绘制它时，会发现它从不与 x 轴相交：

![y = x^2 + 5（mod 17）的图](https://static.wixstatic.com/media/706568_a87f571b1af9454db2b27d4a9fd3d8f6~mv2.png/v1/fill/w_1399,h_864,al_c,q_90,enc_auto/706568_a87f571b1af9454db2b27d4a9fd3d8f6~mv2.png)

它没有根，因为模 17 的有限域无法表示 $\sqrt{5}$。但在有限域 $p = 11$ 中，它会有两个根，因为 5 在有限域 $p = 11$ 中有模平方根。

### ZK 算术电路的局限

如果希望使用有限域上的算术电路证明“我知道多项式 $y = x² − 5$ 的根”，可能会遇到无法编码 $\sqrt{5}$ 的问题。也就是说，在实数上，$y = x² − 5$ 有根 $\sqrt{5}$，但某些有限域无法表示它。取决于 $p$，算术电路 `x² === 5` 可能没有满足见证。

### 使用 Python 处理有限域中的多项式

试验算术电路时，编写 Python 代码进行模拟有时很有帮助。当算术电路具有多项式形式时，可以使用前面介绍的 `galois` 库测试其行为。下面的代码示例说明如何使用该库处理多项式。

### 在有限域中进行多项式加法

下面的代码定义了两个多项式：`p1 = x² + 2x + 102` 和 `p2 = x² + x + 1`，然后以符号方式把它们相加，得到 `2x² + 3x`。请注意，在有限域 `p = 103` 中，常数项相加后为零。

```python
import galois
GF103 = galois.GF(103) # p = 103

# we define a polynomial x^2 + 2x + 102 mod 103
p1 = galois.Poly([1,2,102], GF103)

print(p1)
# x^2 + 2x + 102

# we define a polynomial x^2 + x + 1 mod 103
p2 = galois.Poly([1,1,1], GF103)

print(p1 + p2)
# 2x^2 + 3x
```

`galois` 库能够把负整数解释为加法逆元，如下所示：

```python
import galois
GF103 = galois.GF(103) # p = 103

# We can input "-1" as a coefficient, and that will
# automatically be calculated as `p - 1`
# -1 becomes 102 in a field p = 103
p3 = galois.Poly([-1, 1], GF103)
p4 = galois.Poly([-1, 2], GF103)

print(p3)
# 102x + 1
print(p4)
# 102x + 2
```

### 在有限域中进行多项式乘法

可以把多项式相乘：

```python
print(p3 * p4)
# x^2 + 100x + 2
```

注意，`p3` 和 `p4` 都是一次多项式，其乘积是二次多项式。

### 寻找有限域中多项式的根

寻找有限域上多项式的根是另一个独立主题（相关算法参见 Wikipedia 的[有限域上多项式因式分解](https://en.wikipedia.org/wiki/Factorization_of_polynomials_over_finite_fields)页面）。`galois` 库可以使用 `roots` 函数计算根。这有助于验证多项式形式的算术约束是否确实创建了预期约束。

```python
print((p3 * p4).roots())
# [1, 2]
```

### `galois` 库的注意事项

该库会静默向下取整作为系数传入的浮点数：

```python
# The galois library will silently convert
# floats into a integer
galois.Poly([2.5], GF103)
# Poly(2, GF(103))
```

如果传入大于或等于 `p` 的数，库会报错：

```python
# The follow code fails because we cannot
# have coefficients the order of the field or higher
galois.Poly([103], GF103)
# ValueError: GF(103) arrays must have elements in `0 <= x < 103`, not [103].
```
