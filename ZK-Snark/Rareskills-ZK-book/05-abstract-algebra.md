# 抽象代数

抽象代数研究的是配备一个或多个运算的集合。就本文而言，我们只关心运算为二元运算的集合。

给定一个配备二元运算的集合，可以根据二元运算的行为，以及集合允许（或预期）包含哪些元素，对它进行分类。

数学家为二元运算在集合上的每一种可能行为都准备了术语。作为应用程序员，我们主要关心群论中的“群”，但先循序渐进地走到那里。群只是这个大型动物园中的一种动物。与其孤立地研究群，不如把它放在相关代数结构（即配备二元运算的集合）的更大背景中考察。

抽象代数是一个庞大的领域，但本文的目标是清楚理解什么是*群*，因为它在零知识证明中无处不在。现在当然可以直接给出定义：

*群是一个配备二元运算的集合，该运算封闭、满足结合律，集合中存在单位元，并且每个元素都有逆元。*

不过，这个简短定义并不能说明多少问题。结合更广泛的抽象代数背景理解群，会更有帮助。

## 原群（Magma）
原群是配备封闭二元运算的集合，仅此而已。

作为程序员，你肯定已经凭直觉理解原群，现在只不过知道了它的名称。

例如，考虑所有正整数组成的集合，并把二元运算定义为 $x^y$。请注意，我们不允许负数，因为 $y$ 为负时会得到分数。

显然，输出仍在整数空间中。这个函数是 $(\mathbb{Z}\times\mathbb{Z})$ 与 $\mathbb{Z}$ 的笛卡尔积所构成关系的一个子集。具体来说，$x^y$ 是从 $(\mathbb{Z}\times\mathbb{Z})$ 到 $\mathbb{Z}$ 的函数。

有趣的是，这个例子既不满足交换律，也不满足结合律。可以在下面的 Python 代码中为 `a`、`b` 和 `c` 选择具体值，自行验证：

```python
assert a ** (b ** c) != (a ** b) ** c
assert a ** b != b ** a
```

但这并不重要。原群是限制最少的*代数结构*之一，唯一重要的是二元运算封闭，其他行为都不受限制。

*代数结构*是一个集合及其上的一组运算。就本文而言，我们只关心二元运算。

## 半群（Semigroup）
半群是二元运算满足结合律的原群。

所有半群都是原群，但并非所有原群都是半群。

换句话说，半群是配备封闭且满足结合律的二元运算之集合。

令我们的（无限）集合为传统字母表 a、b、c、…、x、y、z 所能组成的所有非空字符串。例如，“az”“programmer”“zero”“asdfghjk”“foo”和“bar”都属于该集合。

令二元运算为字符串拼接。该运算封闭，因为结果仍是集合中的字符串。


请注意，交换“foo”和“bar”的顺序后，输出字符串并不相同，分别是“foobar”和“barfoo”。不过，这没有关系。“foobar”和“barfoo”都是集合成员，所以“拼接”这一二元运算是封闭的。因为这是一个配备封闭且满足结合律之二元运算的集合，所以所有字符串在拼接运算下构成半群。

**练习：** 自行验证按顺序拼接“foo”“bar”“baz”满足结合律。请记住，结合律意味着 $(A \square B) \square C = A \square (B \square C)$，其中 $\square$ 是半群的二元运算。

**练习：** 分别举出一个原群和一个半群，且该原群不能是半群。不要使用上面的例子。也就是说，对原群，需要想出一个封闭但不满足结合律的二元运算；对半群，二元运算必须既封闭又满足结合律。

## 幺半群（Monoid）
幺半群是具有单位元的半群。


没错，这正是“单子是自函子范畴中的幺半群”那句话里的幺半群。

![关于单子教程的数学梗图](https://static.wixstatic.com/media/935a00_bd9a8814842b4359b63050555a1c1c95~mv2.png/v1/fill/w_500,h_991,al_c,q_90,enc_auto/935a00_bd9a8814842b4359b63050555a1c1c95~mv2.png)

查看 Scala 的 Cats 库中关于[幺半群的文档](https://typelevel.org/cats/typeclasses/monoid.html)，可以明确看到这些定义：

```scala
trait Semigroup[A] {
    def combine(x: A, y: A): A
}

trait Monoid[A] extends Semigroup[A] {
    def empty: A
}
```

Cats 库只是把“单位元”称为 `empty`，把二元运算称为 `combine`。Monoid 扩展 Semigroup 这一事实表明，幺半群是要求存在“empty”（单位元）的半群。

上面的代码片段没有展示这一点，但 combine 确实还必须满足结合律。

半群只有一个二元运算，除了输出必须与输入相同为类型 `A`（输入为 `x` 和 `y`）外，没有其他限制。

例如，不含零的正整数在加法下构成半群；加入零后，它就成为幺半群。


*单位元*是指：对单位元与另一个元素 $a$ 应用二元运算，结果仍为 $a$。例如在加法中，$8 + 0 = 8$，其中 $0$ 是单位元。如果二元运算是乘法，单位元就是 $1$，因为一个数乘以 $1$ 仍得到自身。

如果集合是所有 $2\times 2$ 矩阵，二元运算是矩阵乘法，那么单位元是单位矩阵：

$$
\begin{bmatrix}
1&0\\
0&1\\
\end{bmatrix}
$$

### 集合的集合上的并集与交集
我们此前讨论集合时，奇怪地没有提到集合的并集与交集。它们都是二元运算，现在正适合介绍。

对集合 $\set{1,2,3,4}$ 和 $\set{3,4,5,6}$ 取并集，会得到 $\set{1,2,3,4,5,6}$。对 $\set{1,2,3,4}$ 和 $\set{3,4,5,6}$ 取交集，则会得到 $\set{3, 4}$。

很明显，这两个运算都满足结合律。

如果把定义域设为由所有有限整数集合构成的集合，那么并集和交集这两个二元运算都是封闭的，因为结果仍是整数集合。

在这个定义域中，集合并集存在单位元：空集 $\set{}$。任意集合与空集取并集，得到原集合，即 $A \cup \set{} = A$。

因此，所有*有限*整数集合在并集运算下构成幺半群。

但所有可能的有限整数集合在交集运算（$\cap$）下只构成半群——不存在可以作为单位元的有限集合。不过，如果扩展该集合，把 $\mathbb{Z}$ 自身也包括进来，即在交集运算下使用集合 $\{\text{所有有限整数集合}\}\cup\mathbb{\{Z\}}$，它就成为幺半群，因为 $\mathbb{Z}$ 是单位元。

如果感觉我们把单位元“硬塞”了进来，没错，确实如此。

稍后会看到，椭圆曲线使用了类似技巧：加入一个称为“无穷远点”的特殊点，以便与代数定律保持一致。关键是，如果声称某个集合在某种二元运算下构成幺半群，就必须非常清楚其单位元是什么。

再举一个例子，可以把集合定义为所有正整数再加上额外元素 $\text{mug}$。定义 $\text{mug} + x = x$ 且 $x + \text{mug} = x$。作为系统设计者，我们可以让集合包含任何所需对象，也可以任意定义二元运算的行为。不过，要使这个代数结构成为幺半群，二元运算必须封闭、满足结合律，并且集合必须具有单位元。

如果把定义域限制为 $\set{0,1,2,3,4,5}$ 的所有子集，交集显然构成幺半群，因为单位元是 $\set{0,1,2,3,4,5}$：任意整数集合与它取交集，都会得到另一个集合本身，即 $A \cap \set{0,1,2,3,4,5} = A$。例如，$\set{1,3,4} \cap \set{0,1,2,3,4,5} = \set{1,3,4}$。

到这里应该已经很清楚：对给定二元运算而言，一个代数结构属于哪一类，对集合的定义域极其敏感。

**练习：** 令二元运算为整数上的函数 `min(a,b)`。它构成原群、半群还是幺半群？如果把定义域限制为非负整数（大于或等于零），答案如何？对这两个定义域上的二元运算 `max(a,b)`，答案又如何？

**练习：** 令集合为所有 3 位二进制数（基数为 8 的集合）。候选二元运算包括按位与、按位或、按位异或、按位或非、按位同或和按位与非。显然，这些运算封闭，因为输出仍是 3 位二进制数。对每个二元运算，判断该集合在其作用下构成原群、半群还是幺半群。

## 群——主角登场
群是其中每个元素都有逆元的幺半群。

明确来说，它是具有以下四个性质的集合：

1. 二元运算封闭（原群）；
2. 二元运算满足结合律（半群）；
3. 集合具有单位元（幺半群）；
4. 每个元素都有*逆元*。

也就是说，对集合 $A$ 中任意元素 $a$，都存在 $a'$，使 $a \square a' = i$，其中 $i$ 是单位元，$\square$ 是二元运算。用更数学化的语言表示：

$$
\forall a \in A \space\space \exists a' \in A: a\square a' = i
$$

这里，$\square$ 是该集合的二元运算。

说“这个集合有一个逆元”并不准确。严格来说，每个元素在集合中都有另一个元素作为它的逆元。

对加法下的整数而言，单位元是零（因为加零后仍得到原数），某个整数的逆元则是符号相反的整数，例如 $5$ 的逆元是 $-5$，$-7$ 的逆元是 $7$。

再次回到定义域敏感性：正整数上的加法不构成群，因为其中不存在逆元。

下表进一步说明这一点：

| 集合定义域 | 二元运算 | 代数结构 | 原因 |
|----------------------------------|-----------------|---------------------|------------------------------|
| 非零正整数 | 加法 | 半群 | 没有单位元 |
| 包含零的非负整数 | 加法 | 幺半群 | 有单位元，但没有逆元 |
| 所有整数 | 加法 | 群 | 每个元素都有逆元 |

请注意，如果集合没有单位元，“逆元”就没有意义。按照定义，对一个元素及其逆元应用二元运算，结果是单位元。

**练习：** 为什么字符串在拼接运算下不能构成群？

**练习：** 多项式在加法下满足群的性质。请逐一验证它具备定义群的所有性质。

### 关于交换律
以上代数结构都不要求满足交换律。如果满足，就说它们在相应二元运算下是阿贝尔的。在此语境中，“阿贝尔”表示二元运算满足交换律，即操作数的顺序不影响结果。

阿贝尔意味着二元运算满足交换律。

不过说“阿贝尔”会让你显得更聪明。

严格来说，通常不说“加法是阿贝尔的”，而是说“这个群在加法下是阿贝尔群”。

## 再谈子集
把所有内容与开头所学联系起来。原群、半群、幺半群和群，都是配备封闭二元运算的集合。二元运算只是一个映射：从集合与自身之笛卡尔积中的所有有序对，映射回该集合本身。


群是幺半群的子集，幺半群是半群的子集，半群是原群的子集，原群则是一般集合的子集。每个群也都是原群和集合，但原群不一定是群。

“集合”很容易形象化，但开始讨论群及其他代数结构时，很容易迷失。群在密码学学习中非常重要，只需记住：


**群是配备遵循四条规则之二元运算的集合。**


另外，也应该摆脱“加法”和“乘法”是组合对象之主要方式的思维限制。


可以对任意集合（其中可以包含任何对象）与自身取笛卡尔积，再把这个有序对集合映射回原集合。这就是二元运算。如果遵循上述构造，该运算就是封闭的。

## 无需畏惧数学词汇
在开始本教程之前，下面这句话可能毫无意义：

“字符串集合在字符串拼接这一二元运算下，是半群还是幺半群，取决于集合中是否存在空字符串。”

像大多数第二语言学习者一样，你可能仍需在脑中翻译它，但现在应该已经意识到，这句话把大量信息压缩进了很小的空间。

能不能不用这么数学化的语言表达这句话？当然可以，但要讲清楚至少需要 500 个词。理解这些术语的含义确实值得，从长远来看会省去许多麻烦。

更酷的是，关于群存在大量定理，使我们即使*不了解群的二元运算在内部如何工作*，也能对群作出判断。这有点类似面向对象编程中的多态，或函数式语言中的 trait：它们隐藏实现细节，让你专注于高层结构，这非常强大。
