# 使用 Python 实现拉格朗日插值

拉格朗日插值（Lagrange interpolation）是一种计算多项式的技术，所得多项式会经过给定的 $n$ 个点。

## 把向量插值为多项式
### 示例

#### 经过两个点的直线
如果有两个点，就可以用一条直线对它们进行插值。例如，给定 $(1, 1)$ 和 $(2, 2)$，可以画出一条与这两个点相交的直线，也就是次数为 $1$ 的多项式 $y = x$。

#### 单个点
如果只有一个点，可以用零次多项式画出一条经过该点的直线。例如，如果点为 $(3, 5)$，就可以画出经过它的直线 $y = 5$，这是一个次数为 $0$ 的多项式。

#### 三个点与抛物线
这种规律对任意数量的点都成立：可以用一个次数至多为 $n - 1$ 的多项式“经过”$n$ 个点。例如，可以使用 $y = x^2$ 对点 $(0, 0), (1, 1), (2, 4)$ 进行插值。如果这些点恰好位于同一条直线上，例如 $(0, 0), (1, 1), (2, 2)$，则可以使用一次多项式 $y = x$ 画出经过 $(1, 1)$ 和 $(2, 2)$ 的直线。不过一般情况下，三个点并不共线，因此需要一个二次多项式经过所有点。

## 拉格朗日插值的 Python 代码
就本文的目的而言，不必理解如何手动计算该多项式，因为数学库可以代为完成。最常用的算法是*拉格朗日插值*，下面展示如何在 Python 中实现。

#### 浮点数示例
可以使用拉格朗日插值计算经过点 $(1,4), (2,8), (3,2), (4,1)$ 的多项式 $p(x)$。

```python
from scipy.interpolate import lagrange
x_values = [1, 2, 3, 4]
y_values = [4, 8, 2, 1]

print(lagrange(x_values, y_values))
#      3      2
# 2.5 x - 20 x + 46.5 x - 25
```

#### 有限域示例
继续使用前面的点，但这次用有限域 $\mathbb{F}_{17}$ 代替浮点数。

```python
import galois
import numpy as np
GF17 = galois.GF(17)

xs = GF17(np.array([1,2,3,4]))
ys = GF17(np.array([4,8,2,1]))

p = galois.lagrange_poly(xs, ys)

assert p(1) == GF17(4)
assert p(2) == GF17(8)
assert p(3) == GF17(2)
assert p(4) == GF17(1)
```

### 插值多项式的唯一性
回到点 $(1, 1), (2, 2)$ 的例子，对它们进行插值的最低次数多项式是 $y = x$。一般而言：

**对一组 $n$ 个点，存在唯一一个次数最低且次数至多为 $n - 1$ 的插值多项式。**

对这些点进行插值的最低次数多项式，有时称为*拉格朗日多项式*。

由此可知：

**如果使用点 $(1,2,...,n)$ 作为 $x$ 值，通过拉格朗日插值把长度为 $n$ 的向量转换为多项式，那么所得多项式是唯一的。**

换句话说，只要使用一组一致的 x 值作为向量插值的基，就存在唯一一个对给定向量进行插值的多项式。也可以说，每个长度为 $n$ 的向量都有唯一的多项式表示。

非正式地说，每个长度为 $n$ 的向量都有唯一一个次数至多为 $n - 1$ 的多项式来“表示”它。例如，当各点共线时，多项式次数可能更低，但向量对应的最低次数多项式仍然唯一。

“最低次数”这一限定很重要。给定两个点，会有极多不同的多项式经过它们，但其中次数最低的多项式是唯一的。
